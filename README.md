# 6号機ジャグラー 設定推測ツール v2

スマートフォンでの入力を優先した、外部通信なしの静的Webサイトです。
GitHub Pagesへそのまま公開できます。

## 主な機能

- 6号機ジャグラー各機種のBB・RB・合算・出玉率を登録
- 総回転数、BB、RB、差枚から設定1〜6の相対確率を計算
- 設定4以上・設定5以上・推定設定平均を表示
- 大型テンキーでボーナス履歴を登録
- BIG、REG、現在G数をワンタップで入力
- 履歴の1件削除、全消去、新しい順・古い順の切り替え
- 履歴から総回転数・BB・RBを自動集計
- 100G・200G…1000G以内の当選率を設定別に比較
- CSV出力
- ブラウザ内への自動保存
- スマートフォン用の画面下固定「設定を推測する」ボタン

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの内容をリポジトリへアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. Branchを `main`、Folderを `/docs` に設定して保存します。
6. 数分後、Pagesの公開URLが表示されます。

相対パスだけを使用しているため、リポジトリ名が変わっても動作します。

## ローカル確認

`docs/index.html` を直接開くか、次のように簡易サーバーを起動します。

```bash
cd docs
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 計算方法

- BB・RB・非当選の多項尤度を設定別に計算
- 差枚は公表出玉率から求めた期待差枚との整合度として弱く合成
- 差枚補正は0〜50%で変更可能
- 履歴区間は診断表示に使用し、主判定への二重加点はしない

## 注意

- 実設定を確定するものではありません。
- 低回転では確率が大きく変動します。
- 履歴を集計値へ反映する場合は、当日の全履歴を入力してください。
- 入力内容は端末のブラウザ内に保存され、外部へ送信されません。
