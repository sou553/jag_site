# 6号機ジャグラー 設定推測ツール v14

GitHub Pagesで動作する静的Webアプリです。

## v14の主な変更

- 実測小役を独立した二項分布の加算から、多項分布へ変更
- 入力した小役と「その他」の回数を同時に評価し、同一ゲームの二重評価を回避
- 入力小役の合計が計測G数を超える場合の検証を追加
- 判別強度に最有力確率、1位と2位の差、総回転数を使用
- 1位と2位の設定番号・相対確率を結果画面へ追加
- 機種データへ出典、データ種別、更新日、確認日を追加
- 機械割を「公表値」「チェリー狙い参考値」「概算補間」に分離
- 概算補間は詳細選択時のみ表示し、実測値ではないことを明記
- コイン持ちの掲載値と取得率概算を別の選択欄へ分離
- スマートフォンのヘッダーとタブを縮小
- モバイルのタブ名を「履歴」「データ」「説明」へ短縮
- 機種データ表で設定列が重複していたv13の表示不具合を修正
- CSS・JavaScriptへ`?v=14`を付け、更新時のアセットキャッシュを回避

## 小役の多項分布

入力した小役を `j = 1...k`、計測ゲーム数を `G` とします。

```text
その他回数 = G - Σ x_j

log L(s)
= Σ x_j log q_j(s)
+ その他回数 × log(1 - Σ q_j(s))
```

`q_j(s)`は設定ごとの小役確率へ捕捉率を掛けた観測確率です。
組合せ係数は全設定で共通なので、設定間の相対比較では省略しています。

小役が1種類だけの場合は、従来の二項分布と同じ形になります。

## 機械割

- 公表値：メーカー公表の適当打ち基準
- チェリー狙い参考値：ジャグラー設定判別ツールNEOの独自計算値
- 概算補間：上記2値の直線補間。実測値ではありません
