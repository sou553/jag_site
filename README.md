# 6号機ジャグラー 設定推測ツール v3

総回転数・BB・RB・差枚・逆算ブドウ・ボーナス履歴から、設定1〜6の相対確率を計算する静的Webサイトです。

## v3の変更点

- 差枚のプラス／マイナス切り替えボタンを追加
- 総回転数・差枚・BB・RBの初期値を0に変更
- 設定1〜6の投入配分をユーザーが変更可能
- 均等、低設定寄り、中間中心、強い日の配分プリセット
- 差枚からブドウ回数とブドウ確率を逆算
- BB・RB尤度と逆算ブドウ尤度を重み付きで統合
- 逆算の総アウト、ボーナス、リプレイ、チェリー、ブドウ内訳を表示
- 入力中はスマートフォン下部の固定ボタンを非表示にし、キーボードとの重なりを軽減
- GitHub Pagesでそのまま公開できる `/docs` 構成

## GitHub Pagesへの公開

1. ZIPを展開してリポジトリへアップロード
2. GitHubの `Settings` → `Pages`
3. `Deploy from a branch`
4. Branchを `main`
5. Folderを `/docs`
6. 保存

`docs/index.html`、`docs/style.css`、`docs/app.js` の3ファイルだけで動作します。

## ブドウ逆算

標準設定では次の式を使用します。

- 総アウト = 総回転数 × 3 + 差枚
- ボーナス獲得 = BB回数 × 機種別BIG獲得枚数 + RB回数 × 96
- リプレイ推定 = 総回転数 ÷ 7.298 × 3
- チェリー推定 = 総回転数 ÷ 34.66 × 2 × 取得率
- ブドウ獲得 = 総アウト − ボーナス獲得 − リプレイ推定 − チェリー推定
- ブドウ回数 = ブドウ獲得 ÷ 8
- ブドウ確率 = 総回転数 ÷ ブドウ回数

これは実測ブドウではなく推定値です。ベル・ピエロ、取りこぼし、ボーナスを揃えるまでのロス、データカウンターの集計差は含みません。

## データについて

ボーナス確率・出玉率は北電子の製品情報を基準にしています。ブドウ確率はメーカー公表値ではなく、解析・逆算による参考値です。サイト内ではブドウの重みを0〜70%で調整できます。
