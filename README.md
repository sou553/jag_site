# 6号機ジャグラー 設定推測ツール v15.0.0

GitHub Pagesで動作する静的Webアプリです。

## バージョン情報

- アプリ版: `15.0.0`
- リリースチャンネル: `stable`
- 保存スキーマ: `15`
- データ版: `2026.07.26-r2`
- ビルドID: `20260726-131142-v15`
- ビルド日時: `2026-07-26T13:11:42Z`

`docs/version.json`にも同じ情報を保存しています。公開ページは起動時に`version.json`をキャッシュ無効で取得し、HTML・JavaScript内のビルド情報と照合します。

## v15.0.0の変更

- ヘッダーと仕様ページへ詳細なバージョン情報を追加
- `version.json`による公開版の自動照合を追加
- CSS・JavaScriptへ`?v=15.0.0`を付与
- スマートフォンではテーマボタンとメニューボタンを横並び
- 入力例・全消去・バージョン情報をスマートフォンのメニューへ集約
- 「信頼度」を「データ量」、「判別強度」を「結果分離度」へ整理
- 結果分離度は設定配分を除いた証拠のみの確率で計算
- 最終確率差と証拠のみの確率差を分けて表示
- 機種ごとに詳細ボーナス入力の可否を自動判定
- 詳細データ未登録機種では詳細入力を無効化
- ゴーゴー3、マイジャグラーV、ファンキー2でレアチェリー重複BIGへ対応
- 履歴へ内訳不明BIG／REGとレアチェリー重複BIGを追加
- 小役多項分布の総合支持設定を判定根拠へ追加
- 保存キーを固定し、`schemaVersion`で管理
- v7〜v14の保存データを自動移行
- 全機種比較表を選択中の機械割モードへ連動

## 公開版の確認

公開後、次のURLでバージョン情報を直接確認できます。

```text
https://sou553.github.io/jag_site/version.json
```

画面の「説明」→「公開バージョン情報」でも一致状態を確認できます。

## 保存データ

新しい保存キーは固定です。

```text
juggler-setting-analyzer
```

保存内容には次を含めます。

```json
{
  "schemaVersion": 15,
  "appVersion": "15.0.0"
}
```

旧キーのデータが存在する場合は、最も新しい保存内容を読み込み、schema 15へ変換します。

## 詳細ボーナス入力

詳細入力に対応する条件は、次の設定別データがすべて登録されていることです。

- 単独BIG
- 単独REG
- チェリー重複BIG
- チェリー重複REG

レアチェリー重複BIGが登録されている機種では専用欄を追加表示します。
