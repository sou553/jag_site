# 6号機ジャグラー 設定推測ツール v13

GitHub Pagesで動作する静的Webアプリです。

## v13の主な修正

- 差枚未入力と差枚0枚を明確に区別
- 差枚未入力時は逆算ブドウを設定推測から完全に除外
- ボーナス入力を「かんたん入力」と「詳細入力」に分離
- かんたん入力ではBB合計・RB合計だけで判定
- 詳細入力では単独・チェリー重複・内訳不明を入力
- ボーナス履歴の追加・削除・現在G数を台データへ自動同期
- 手動で台データを変更した場合は履歴同期を一時解除
- ヘッダー表現を「履歴も設定尤度に加える」ように見えない内容へ修正
- 結果画面へ判定根拠、1位と2位の差、低設定域・高設定域確率を追加
- BB、RB、合算、単独／重複、小役、設定配分、履歴同期の使用状況を表示

## 差枚

- 空欄：差枚を使用しない
- `0`を明示入力：差枚0枚として逆算ブドウを計算
- 正負は左側の＋／−ボタンで指定

## かんたん入力

```text
総回転数
差枚（任意）
BB合計
RB合計
```

単独・重複の内訳は使用しません。

## 詳細入力

```text
単独BIG
チェリー重複BIG
内訳不明BIG
単独REG
チェリー重複REG
内訳不明REG
```

内訳不明分は総BB・総RBには含めますが、単独／重複比率の追加尤度には使いません。

## 履歴の自動同期

履歴を追加・編集すると、以下を台データへ自動反映します。

- 総回転数
- BB・RB合計
- 単独BIG・REG
- チェリー重複BIG・REG
- 内訳不明BIG・REG

履歴のハマりや100G以内率は診断表示だけに使用し、BB・RB尤度へ重複加算しません。
